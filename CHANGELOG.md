# Changelog

Changes follow the categories used by Keep a Changelog. No production application release is recorded yet.

## Unreleased — 1.0 Stage 1

### Added

- Monochrome GYRO-TARGET-1.0 A4/US Letter vector PDFs and offline target tools.
- Automatic target acquisition from image regions and observed orbital motion.
- First-run guide, offline EN/DE/ES/RU instructions and German/Spanish resources.
- Public documentation, issue templates and documentation validation workflow.

### Changed

- Product release numbering starts at 1.0.0-stage1; Android versionCode increases from the earlier UI 3.0 build.
- The official target uses a black mark for monochrome printing, superseding the initial green-target proposal.
- Official-target readiness uses geometry validation rather than the manual path's fixed minimum elapsed-time gate.

### Fixed

- Acquisition association accounts for gaps between delivered frames.

### Removed

- No previous measurement capability intentionally removed.

Earlier internal builds are development history, not public production releases.
