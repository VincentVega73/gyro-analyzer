# Changelog

Changes follow the categories used by Keep a Changelog. No production application release is recorded yet.

## Unreleased — 1.0 Stage 1

### Field documentation — GYRO-107, 2026-11-05

- Updated the existing methodology and uncertainty papers with four official black-target physical sessions and independent numerical reproduction.
- Added seven measured-data figures, explicit phase/export semantics and exploratory unloaded/playback comparison; no causal stylus-drag or absolute-accuracy claim.
- Reclassified target evidence from no physical tests to initial field evidence while retaining broader acceptance gaps. No Android measurement algorithm changed.

### Documentation — 2026-11-05

- Published implementation-based measurement methodology and uncertainty papers for algorithm 2.2.1, with original diagrams and fresh aggregate validation results.
- Added an evidence register and navigation index. Historical invalidation statuses and missing before/after adjustment evidence are explicitly retained.
- No Android measurement algorithm changed; official printed-target physical acceptance remains pending.

### Added

- Monochrome GYRO-TARGET-1.0 A4/US Letter vector PDFs and offline target tools.
- Automatic target acquisition from image regions and observed orbital motion.
- First-run guide, offline EN/DE/ES/RU instructions and German/Spanish resources.
- Public documentation, issue templates and documentation validation workflow.

### Changed

- Product release numbering starts at 1.0.0-stage1; Android versionCode increases from the earlier UI 3.0 build.
- The official target uses a black mark for monochrome printing, superseding the initial green-target proposal.
- Official-target readiness uses geometry validation rather than the manual path's fixed minimum elapsed-time gate.

### Fixed

- Acquisition association accounts for gaps between delivered frames.

### Removed

- No previous measurement capability intentionally removed.

Earlier internal builds are development history, not public production releases.
