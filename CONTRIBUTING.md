# Contributing

This repository accepts documentation corrections, reproducible bug reports and device/measurement reports. The Android source is private; do not submit extracted application code, private logs or unlicensed third-party material.

Use English for public contributions. Read the relevant guide, check existing issues and use the closest issue template. Explain observed behaviour, expected behaviour and reproducible steps. Distinguish measurements from hypotheses; do not claim certified accuracy without traceable evidence.

Documentation pull requests should update related guides and keep links valid. Run the repository validation script and Markdown lint. Do not change the target geometry without a reviewed versioned standard and matching detector validation. The private generator is not part of this repository.

Licensing terms remain under owner review. Do not contribute third-party copyrighted material or assume that submission grants a licence for unrelated uses. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
