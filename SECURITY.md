# Security

## Supported scope

This repository contains documentation and printable resources. The application is still in development; no production support policy is established.

## Reporting a vulnerability

Use GitHub private vulnerability reporting through the Security tab when enabled: [report privately](https://github.com/VincentVega73/gyro-analyzer/security/advisories/new). If unavailable, do not disclose exploit details in a public issue. Ask the owner to enable a private channel without posting sensitive details. No unverified personal email address is published.

Provide affected version, impact, reproducible steps and a minimal non-sensitive example. Do not upload signing keys, credentials or unreviewed diagnostic images. No guaranteed response time or bounty is offered.

## Repository controls

Documentation CI uses read-only repository permissions, validates a public-file allowlist, scans for common secret patterns and checks links/PDF metadata. GitHub secret scanning and push protection should be enabled where available. These checks are defence in depth and do not constitute a guarantee that every secret format is detected.
