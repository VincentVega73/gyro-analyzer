# Android RC media policy alignment (1.5.1)

The integration specification requires documented manufacturer permission for a photo-derived sketch, or an independent multi-view construction study. Nine existing reference-redraw assignments have photo license evidence, but no recorded manufacturer permission. This is an evidence gap against the requested workflow, not a finding that the source licenses are invalid.

For this RC those assignments use clearly labeled generic illustrations. The original drawings and evidence remain in the source repository, unmodified and excluded from the Android asset bundle. No new artwork was generated. Michell Gyro SE and Arcturus 006 retain independent-study illustrations, including their factory/manual and multi-view evidence and visual review.

Coverage: 1,639 models = 2 individual + 0 family + 1,637 generic + 0 missing/corrupt. Four related designations remain generic. Six unique WebP files are packaged. Model IDs, aliases, specifications, sources and schema 3 are unchanged; catalog edition increments to 1.5.1.
