# Getting started

## Availability

The product is in Stage 1 development. The documentation describes the 1.0.0-stage1 test build. There is no published Google Play listing or public install package yet. Obtain test builds only through the project owner's agreed testing channel. Never use an unrelated APK download site as an official source.

## Requirements

Android 8 (API 26) or later, a functioning rear camera, a stable phone support, a rotating platter and a printed target are required. A printer is needed only to prepare the paper. Network access is not required by measurement, history, target access or the offline guide. PDF preview requires an installed viewer; printing requires an Android print service or saving the PDF for another device.

## First launch

The guide explains the optical method, opens the target tools, describes installation and leads to Calibration. You may open the main screen without finishing it and restart the guide from Help. Camera permission is requested for the preview, not for reading instructions. If denied, enable Camera in Android's app settings and return to Calibration.

Use [the complete guide](user-guide.md) for the full workflow. Read [compatibility](compatibility.md) before assuming a high-speed camera mode is supported.
