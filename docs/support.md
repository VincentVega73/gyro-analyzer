# Support and feedback

Use [Issues](https://github.com/VincentVega73/gyro-analyzer/issues) for reproducible defects and documentation corrections. Use [Discussions](https://github.com/VincentVega73/gyro-analyzer/discussions) for usage questions, measurement interpretation and device reports. Support is community-based; no response-time guarantee is made.

For a measurement problem, include app version, Android version, phone model, requested/delivered FPS, resolution, camera orientation, target version, print scale, paper/printer type, light, mount, nominal speed, duration, exact status and steps to reproduce. Say whether the input is a live recording or CSV replay. Include quality warnings instead of reporting only the final RPM.

If available, attach a reviewed CSV or a cropped screenshot without private background information. Diagnostic ZIPs may contain camera images. Never post tokens, signing files, personal addresses or confidential scenes. For vulnerabilities, follow [SECURITY.md](../SECURITY.md), not a public issue.
