# Validation status

The target PDF has reproducible physical geometry, one vector black mark, a 50 mm ruler and embedded GYRO-TARGET-1.0 metadata. Software checks cover page sizes, vector paths and target dimensions. Synthetic sequences are rendered from the actual PDF and exercise rotation, tilt, lighting, blur, frame gaps, occlusion and rejection cases. See the [software validation results](software-validation.md).

Physical print/device tests and independent-reference accuracy characterization are pending. Neither the 98%/95% acquisition goals nor the 10-second physical readiness goal are claimed as achieved. Production release is blocked on acceptance. See [physical protocol](physical-test-protocol.md).
