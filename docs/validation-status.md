# Validation status

The target PDF has reproducible physical geometry, one vector black mark, a 50 mm ruler and embedded GYRO-TARGET-1.0 metadata. Software checks cover page sizes, vector paths and target dimensions. Synthetic sequences are rendered from the actual PDF and exercise rotation, tilt, lighting, blur, frame gaps, occlusion and rejection cases. See the [software validation results](software-validation.md).

Four owner-supplied physical sessions with the official black target now demonstrate initial field operation, final accepted calibration and RPM output. See [field results](accuracy-and-uncertainty.md#field-validation-with-the-official-optical-target). Broader print/device acceptance and independent-reference accuracy characterization remain incomplete. Neither the 98%/95% acquisition goals nor the 10-second physical readiness goal are claimed as achieved. Production release is blocked on acceptance. See [physical protocol](physical-test-protocol.md).
