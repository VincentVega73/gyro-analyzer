# Gyro Optical Target

Version: **GYRO-TARGET-1.0**. Development target; physical printer/device acceptance remains pending.

| Property | Value |
| --- | --- |
| Paper formats | A4: 210 × 297 mm; US Letter: 215.9 × 279.4 mm |
| Working disc | White, 180 mm diameter |
| Spindle opening guide | 7.5 mm diameter; adjust safely to fit |
| Marker | One black circle, 12 mm diameter |
| Marker-centre radius | 65 mm |
| Control line | 50 mm |
| Preparation scale check | 49.5–50.5 mm control line |
| Recommended minimum marker image | 12 pixels across |

Download [A4](gyro-optical-target-a4.pdf) or [US Letter](gyro-optical-target-letter.pdf). Print at 100% without fitting to page. Use matte white paper and black-and-white printing. All helper text is outside the working disc. PDF metadata records the standard version and geometry; both files are vector drawings.

See [preparation](../docs/target-preparation.md), [validation](../docs/validation-status.md) and [licensing status](../docs/licensing-status.md). The generator and synthetic sequence generator remain in the private development workspace; the public CI validates the delivered PDFs without access to that workspace.
